# Backend verification

With Java 25 and Maven available, run `mvn test`. Testcontainers uses Docker to start PostgreSQL for Flyway, JPA schema, and persistence checks.

1. Sign in and verify that signing out ends access.
2. Create a simulated transformer and run a scenario with an absolute target value.
3. Register a real transformer without optional specifications and link its temperature sensor.
4. Archive and restore a test transformer. Check that it returns to active inventory.
5. Run a reversible action and use **Deshacer último** to restore the previous state.
